# Game Lab

A playful browser-based place to write, test, and share small games with HTML, CSS, and JavaScript.

## Try it online

After GitHub Pages is enabled for this repository, the site will be available at:

https://ksoposh17.github.io/game-lab/

## Features

- Edit game code in the browser and run it in a sandboxed preview.
- Load three starter projects: Click the Target, Color Mixer, and Number Guess.
- Save a draft in this browser, download a standalone HTML game, or copy a share link.
- Share links include the current game code in the URL fragment. The code is not uploaded to a server.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. The included workflow deploys the site whenever you push to the `main` branch.
4. Once the workflow finishes, visit the URL above.

## Notes

This is a static website; no account system or server-side game gallery is included. Browser saves are local to each device. Share links carry code in the link itself, so only share code you are comfortable making public.

## Customize

Edit `index.html` and commit your changes. GitHub Actions will publish the update.
